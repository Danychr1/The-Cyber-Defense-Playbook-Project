# Firewall Log Review

In this lab, we’ll be diving into a log file from a Cisco ASA firewall using r-base-core for analysis.

And wow… let’s just say these logs aren’t exactly friendly to work with.

Fortunately, with a bit of Bash scripting magic, we can turn that chaos into something meaningful.

Let’s get started by firing up a Kali Linux instance, and let’s begin.

1. R-base-core (the statistical tool):
This is the software that lets you do mathematical analysis. Install it on Kali with:

```bash 
sudo apt update
sudo apt install r-base-core
```
